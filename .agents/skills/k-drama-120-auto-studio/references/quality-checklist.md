# Production quality checklist

- [ ] All visual assets are photorealistic live action; no comic, webtoon, anime, illustration, CGI-looking output.
- [ ] Original screenplay; no copying protected characters or scripts.
- [ ] Characters' reference IDs, facial features, ages, wardrobe and hair remain consistent.
- [ ] Each video shot has a single legible action and believable movement.
- [ ] Lighting, geography, props, continuity, and eyelines match adjacent shots.
- [ ] Spoken Korean is natural; lip-sync checked; no unintentionally generated audio.
- [ ] Unused TTS/voice assets were not generated.
- [ ] Every billed job has user approval, cost estimate and status logged.
- [ ] No hidden retries or auto-upgrades beyond budget cap.
- [ ] Dialogue/music/SFX licensing and AI disclosures checked.
- [ ] Full rendered runtime measured rather than inferred from scene plan.
- [ ] Final upload visibility private until explicit public-release approval.
