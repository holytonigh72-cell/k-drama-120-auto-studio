# 5분 제작 잔여 크레딧 산출

견적 조회는 `abocado_check_cost`를 사용했습니다. 조회만 했으며 추가 크레딧 차감은 없습니다.

## 현재 상태
- Abocado 잔액: **34,020 크레딧** (구독 33,962, 기타 58)
- 기존 완료 결과: 12초 영상 1개와 한국어 TTS 4개. 이미 과금된 비용은 영상 2,410 + 음성 194 = **2,604 크레딧**이며, 잔여 필요량에서 제외했습니다.
- 기존 음성 길이: 31.488초, 27.888초, 62.184초, 10초로 총 **131.56초**. 세 파일이 립싱크 14초 제한을 넘으므로 FFmpeg로 잘라 작업해야 합니다.

## 추천 조합: 720p 생성 + 768P 립싱크, 최종 1080p 로컬 업스케일

| 작업 | 잔여 수량 | 검증 단가 | 잔여 예상 |
|---|---:|---:|---:|
| 장면 이미지 | 24장, 1920×1080, 낮은 품질 | 4장 묶음 137크레딧 | 822 |
| 12초 영상 | 24개, 720p, 대사/생성 음성 끔 | 1개 507크레딧 | 12,168 |
| 기존 TTS 립싱크 | 총 131.56초, 768P, 14초 이하로 분할 | 10초 1,280크레딧 (128/초) | 약 16,840 |
| TTS | 기존 4개 재사용 가정 | 이미 과금됨 | 0 |
| **합계** |  |  | **약 29,830** |

예상 잔액은 약 **4,190크레딧**입니다. 현재 대본과 과거 TTS 텍스트가 일치하지 않는 부분을 편집에서 맞출 수 없다면, 대본 전체 TTS 843자를 새로 생성하는 추가 견적은 **202크레딧**이고 예상 합계는 **30,032**, 잔액은 약 **3,988**입니다.

### 1080p 립싱크 비교

같은 10초 오디오의 립싱크 견적은 768P 1,280크레딧, 1080P 2,560크레딧입니다. 131.56초 전체를 1080P 립싱크로 처리하면 약 33,679크레딧으로 추산되며, 영상·이미지와 합쳐 약 **46,669크레딧**이 필요합니다. 현재 잔액보다 약 **12,649크레딧 부족**합니다. 따라서 720p 영상과 768P 립싱크를 만들고 최종 편집에서 1080p로 업스케일하는 경로가 현재 잔액 안에 들어오는 현실적인 기준안입니다.

## 중요한 가정과 검증 제한
- 잔여 영상 24개는 얼굴 레퍼런스 이미지 1장을 입력으로 쓰는 Seedance V1.5 Pro I2V, 12초, 720p, 생성 오디오 끔으로 견적했습니다. 클립당 507크레딧입니다. 25번째 클립은 기존 12초 영상으로 채웁니다.
- 이미지 견적은 GPT Image 2.5 Flare, 1920×1080, 낮은 품질, PNG, 4장당 137크레딧 기준입니다. 서로 다른 프롬프트를 6묶음으로 생성한다고 가정했습니다.
- 립싱크 총액은 오디오 길이 종량 계산입니다. 실제 파일을 내려받아 14초 이하 구간으로 자른 뒤 각 파일별 `check_cost`를 다시 호출해야 정확한 최종 합계가 확정됩니다. 현재 프로세스에서 Abocado 호스트 DNS가 차단되어 다운로드 실행은 실패했습니다.
- 12초 영상은 이전 프롬프트의 인물/의상/장소가 현재 샷표와 다를 수 있습니다. TTS도 현재 대본과 과거 작업 대사가 일치하지 않는 구간이 있습니다. 이들 자산을 그대로 립싱크 컷에 넣기 전에 스토리·타임라인을 맞춰야 합니다.
- 재시도, 신규 캐릭터 레퍼런스 생성, 음악, 저장 및 외부 서비스 추가 비용은 포함하지 않았습니다. 이 견적만으로 생성은 실행하지 않았습니다.
